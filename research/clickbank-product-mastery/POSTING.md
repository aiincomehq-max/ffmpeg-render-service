# Posting the text-block set

Five silent ~5.5s verticals in `build-text/`. Built to the spec taken off the
one faceless in-niche outlier, @chinglung._.p — 1M views on 4,700 followers.

| file | what it is about |
|---|---|
| `1-cannot-build.mp4` | you can picture your mother's face and not theirs |
| `2-recognise.mp4` | you will recognise them in four seconds, around the eyes |
| `3-almost-them.mp4` | the stranger who is them for half a second |
| `4-already-know.mp4` | the things you know about them that are not a face |
| `5-nothing-happening.mp4` | the flat, idling period before |

## Why these five and not the first set

The first set were cold reads about **someone who already exists** -- he went
quiet, he keeps coming back, she stopped asking. That is generic relationship
tarot. It would build an audience of people ruminating about an ex.

Soulmate Sketch sells **a drawing of the face of someone you have not met.**
So every post now runs on that one premise: you do not have their face, you
have everything except their face, and you would know it instantly if you saw
it. That leaves the viewer wanting exactly the thing the offer provides, which
is what makes the link worth adding later.

Nothing in them mentions the product, names it, or links to it.

## The one step that is not optional

**Add the music inside the Instagram app, at post time.** These ship silent on
purpose.

- Baking a commercial track into the file gets the post muted or taken down.
  In-app audio is licensed, and using it is part of why these travel.
- Pick something slow, vintage and widely recognised. The reference post used
  *500 Miles* — the melancholic-familiar register is the point, not that
  specific song.

## What is deliberately absent

- **No call to action.** Not in the video, not in the caption. The reference has
  none, and it did 1M. Every instinct from the previous five videos said to end
  on "comment your number" — that pattern came from the talking-head posts, not
  this one. Do not add it.
- **No voiceover.** It is read, not listened to.
- **No movement.** All text is on screen from the first frame and never changes.

## Why 5.5 seconds for 110 words

The clip is far shorter than the text takes to read. That is the mechanic. The
viewer replays or pauses, and the loop is what moves it. It is not an error and
it should not be "fixed" by lengthening the video.

## Captions

Keep them near-empty, as the reference does.

```
For entertainment purposes only.
#soulmate #manifestation #tarot #fyp
```

## Cadence and kill rule

One a day for five days on `dreamreach.x`. **If none clears 10,000 views, stop
and do not make more of these.**

The honest caveat: @chinglung._.p has a 98,700-view median on 4,700 followers —
that account was already warm, and its 1M post is only 10.5× its own median, the
lowest multiple in the whole sample. Every genuine standing-start breakout we
found is a human on camera (@_austinbecker_: 1,800-view median → 846K, 458×).
So this format is unproven from a cold start. These five are the cheap test of
whether that matters.

## Background and text scale

The first cut read as a designed quote card; the second was legible only on a
desktop. Where it landed:

- **The background is a photograph, not a drawn gradient.** `plates/wall.png`:
  plain wall, ceiling corner in the upper left, the back of a head and a
  shoulder cropped into the bottom-left corner. The ceiling runs to 15% of the
  frame and the subject starts at 66%, so text sits in the clear band between.
  The original plate's ceiling ran to 35%, which left only 22% for text and is
  what clipped the title. `plates/wall-alt.png` is a ceiling-free take in
  reserve; a real phone photo is still a drop-in swap.
- **Body size is auto-fitted, not fixed.** The build takes the largest size off
  a ladder that still clears the subject's head, then uses one size for all
  five so the set is consistent on a grid. Currently **40px** at 1080 wide,
  with the block spanning 13%–57% of frame height.
- **Word count is the lever on size.** Measuring the reference off a
  low-resolution screenshot produced 26px, which was unreadable on a phone.
  Cutting each post from ~110 words to ~75 bought 40px instead. If the type
  ever needs to be bigger, shorten the copy -- do not move the text down into
  the subject.

## Still true

No links, no product, no affiliate mention while the account is new. And this
does not delay the Taboola test, which is still the actual experiment.
