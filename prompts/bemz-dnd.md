# BEMZ, DND: shot prompts
Hidden motif: the crescent moon (the phone's Do Not Disturb icon). Keep the main figure's face hidden in every shot: no AI copy of BEMZ.
**How to use:** generate the image, then use it as the start frame for image-to-video with the motion prompt. Choose **5s, 9:16**. Save the clip as the file name shown (in `assets/bemz-dnd/`).

**Negative prompt (if the app has one):**
```
cartoon, 3d render, plastic skin, extra fingers, warped text, watermark, warm colours, sunny, faces looking at camera, visible face of the main figure
```
