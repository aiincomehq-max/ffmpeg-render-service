# RIMZEE, HOMETOWN: shot prompts
Hidden motif: the number 73. Shot 1 gets the CCTV overlay and shot 9 the camcorder overlay automatically in the render, so generate them as normal footage. Keep the main figure's face hidden: no AI copy of Rimzee.
**How to use:** generate the image, then use it as the start frame for image-to-video with the motion prompt. Choose **5s, 9:16**. Save the clip as the file name shown (in `assets/rimzee-hometown/`).

**Negative prompt (if the app has one):**
```
cartoon, 3d render, plastic skin, extra fingers, warped numbers, misspelled text, watermark, daylight (except shot 13), clean digital look, faces looking at camera, visible face of the main figure
```
